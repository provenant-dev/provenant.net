Why nothing has worked

We carry the proof all the way through.

Every fix so far treats the symptom. Spam filters, reputation scores, and branded caller ID all guess at who's calling, then block what looks bad. None can prove who's real, so none brought trust back.

The band-aid

  • ✗ Spam filters guess from patterns, then block.
  • ✗ Reputation scores rank likelihood, never truth.
  • ✗ Branded caller ID dresses up an unproven claim.

The cure

  • ✓ The verified truth about who's calling is established the moment a business is vetted.
  • ✓ Today it dies at the first handoff, so everyone downstream falls back to a guess.
  • ✓ Carry that truth all the way through, and the phone works again.

What we built

We invented a way to prove who's really calling.

We invented the model, built it, and Microsoft runs it in production today. The vetter establishes who's real. The network already carries the call. Provenant invented the way it's proven: written into the call and checked independently, so anyone along the way can verify it.

The customer

Live, in production

Microsoft runs on Provenant.

Provenant invented the Open Verifiable Communications (OVC) framework and built its reference implementation. The service has been live with Microsoft since April 2026, proving Microsoft owns the number, is the legal entity behind the call, and has the right to the brand it displays.

Originated as a GSMA Foundry project, showcased at MWC 2026.

“It’s a business need that we had to solve, and we’ve been able to demonstrate the technology to do that with Provenant.” Peter Nilsson, Principal Engineering Leader, Microsoft (Commercial Engineering & AI)
